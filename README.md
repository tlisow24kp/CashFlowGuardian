# 💰 CashFlow Guardian

### Smart Cash Flow Management for Small Businesses

**CashFlow Guardian** is a financial management application designed to help small, township, and rural businesses monitor their cash flow, manage income and expenses, and make better financial decisions.

The application focuses on helping businesses understand their available cash, track financial activities, and identify potential cash shortages before they become serious problems.

---

## 📌 About the Project

Many small businesses generate sales and make profits but still experience financial difficulties because their income and expenses do not occur at the same time.

CashFlow Guardian aims to address this challenge by providing a simple and accessible platform where business owners can record financial transactions, monitor their cash position, and forecast their future cash flow.

The project supports better financial planning, responsible money management, and sustainable business growth.

---

## 🎯 Problem Statement

Small businesses often struggle to manage their cash flow because they do not always have a clear understanding of:

* How much money is currently available.
* How much money is coming into the business.
* How much money is being spent.
* Whether they will have enough cash to cover upcoming expenses.
* When a potential cash shortage might occur.

Without proper cash flow management, businesses may experience financial difficulties even when they generate sales.

---

## 💡 Our Solution

CashFlow Guardian provides a simple financial management solution that allows business owners to record transactions, monitor their cash position, and understand their financial activities.

The application helps users organise their financial information and make more informed decisions about their businesses.

Our goal is to make cash flow management easier, more understandable, and more accessible to small businesses.

---

## ✨ Features

### 📊 Financial Dashboard

Provides an overview of the business's financial position, including:

* Starting cash balance.
* Total recorded income.
* Total recorded expenses.
* Projected cash balance.

### 💵 Income Management

Allows users to record income received by the business and monitor money coming into the business.

### 💸 Expense Management

Allows users to record business expenses and track money going out of the business.

### 📅 Transaction Tracking

Users can record and manage financial transactions using transaction descriptions, amounts, types, and dates.

### 🔮 Cash Flow Forecasting

Provides a forecast of the business's expected cash position over a selected period.

### ⚠️ Cash Shortage Awareness

Helps users identify when their projected cash balance may fall below their selected warning limit.

### 📈 Financial Visualisation

Displays financial information through charts and summaries to make cash flow easier to understand.

### 📥 Data Export

Allows users to download transaction information in CSV format for further analysis and record keeping.

### ⚙️ Business Settings

Allows users to configure business information, starting cash, cash warning limits, and forecast periods.

## 🏗️ System Architecture

CashFlow Guardian follows a simple application structure.

1. **User Interface:** Streamlit provides the interface through which users interact with the application.
2. **Application Logic:** Python processes transactions and calculates financial summaries.
3. **Database:** SQLite stores transaction information.
4. **Data Processing:** Pandas supports financial data analysis and reporting.
5. **Dashboard:** The application presents financial summaries, charts, and cash flow forecasts.

## 🚀 Getting Started

Follow these instructions to run CashFlow Guardian on your computer.

### Prerequisites

Before installing the application, make sure you have:

* Python installed.
* Git installed.
* GitHub Desktop or Git command-line tools.
* A code editor such as Visual Studio Code.

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/tlisow24kp/CashFlowGuardian.git
```

### 2. Navigate to the Project Folder

```bash
cd CashFlowGuardian
```

### 3. Install Dependencies

Install the required Python packages:

```bash
pip install -r requirements.txt
```

### 4. Run the Application

Start the Streamlit application:

```bash
python -m streamlit run app.py
```

### 5. Open the Application

Streamlit will provide a local address in your terminal.

Open the displayed address in your web browser to access CashFlow Guardian.

## 🔐 Data and Security

CashFlow Guardian uses SQLite to store financial transaction information.

The project aims to support responsible handling of business financial data.

Users should avoid entering sensitive personal or banking information into the application.

For public demonstrations, testing, and presentations, sample financial information should be used instead of real business financial records.
